# Idées (registre pré-engagement)

Idées proactives produites par Claude pour améliorer `{{label}}` ou
ses propres capacités sur le projet. Stade **pré-engagement** : ces
items sont en attente de tri par l'utilisateur (promotion vers
backlog/roadmap/improvements, ou rejet).

Convention de gestion :
[`.claude/memory/conventions/ideas-generation.md`](memory/conventions/ideas-generation.md).

## Légende

Statuts :
- **[NEW]** : idée fraîche en attente de tri
- **[DEFERRED]** : examinée mais reportée (avec raison)
- **[PROMOTED -> backlog]** : promue dans `.claude/backlog.md`
  comme action court terme (lien vers item)
- **[PROMOTED -> roadmap]** : promue dans `.claude/roadmap.md`
  comme axe long terme
- **[PROMOTED -> improvements]** : promue dans
  `.claude/improvements.md` (cible outils Claude)
- **[REJECTED]** : rejetée (justifier)

Format d'une idée :

```markdown
- **[STATUT] <titre court>** (proposée YYYY-MM-DD par <author>
  lors de <contexte>)
  - Constatation : <observation factuelle qui motive l'idée ;
    pour topics code-rattachés : `file:line` obligatoire>
  - Idée : <description de l'amélioration>
  - Bénéfice attendu : <pour qui, quoi ; pour topics
    code-rattachés : coût quantifié>
  - Effort estimé : S / M / L
```

Le champ `par <author>` est **obligatoire en mode équipe**, optionnel
en mode solo (cf. `CLAUDE.md § Attribution d'auteur` et
`memory/overview.md § Mode projet`).
